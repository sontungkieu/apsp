# Decisions log

Engineering decisions taken within the scope of the Research Spec / Implementation Guide v1.1.1. None of them
changes the scientific configuration (grammar, reward, scoring path, seed scheme, split, caps, thresholds or
paid-information rules). Where a choice can affect numerics, it is part of the EPH body, so banks/costs made
under a different choice cannot be mixed silently.
